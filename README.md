# Bank Marketing Data Analysis

## Project Overview

This project analyzes Bank Marketing data to understand customer characteristics and marketing campaign performance.

The project uses **Python, SQL and Power BI** to perform data analysis, statistical analysis, SQL querying and interactive dashboard development.

## Dataset

The project uses the Bank Marketing dataset containing customer demographic, financial and campaign-related information.

Important columns include:

* Age
* Job
* Marital Status
* Education
* Balance
* Housing
* Loan
* Contact
* Campaign
* Previous Outcome
* Subscription Outcome

The dataset files are available in the `data` folder.
